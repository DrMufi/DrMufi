I design and ship **production systems for real operators** — shopkeepers, clinic staff, agencies, and back-office teams.

My work sits at the intersection of **product engineering** and **domain software**: money that must balance, stock that must reconcile, clinical workflows that must not break, and installers that must run on ordinary Windows PCs.
